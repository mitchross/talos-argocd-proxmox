# ASUS NUC 13 Pro — November 11, 2026

This page records the ASUS NUC 13 Pro Kit. It runs as the bare-metal Talos worker
`asus-nuc-gen13`. It has one NVMe drive, so it is **compute-only**, with no Longhorn data disk,
like `hp-elite-gen12`. It is a dated snapshot.

## How it joined

1. In the BIOS (F2), Secure Boot is off and network boot is on. F10 opens the one-time boot menu.
2. The NUC booted from the network. [booter](https://github.com/mitchross/talos-argocd-proxmox/blob/main/omni/pi-services/booter/README.md)
   on the Pi served Talos, and the machine appeared in **Omni → Machines** in maintenance mode.
3. `omnictl get machinestatus <uuid> -o yaml` gave the UUID and the NVMe serial.
4. The template `Workers` block copies `hp-elite-gen12` without the Longhorn disk patches.
5. `omnictl cluster template sync` installed Talos to the NVMe. Omni then rebooted it once to add
   the system extensions. The node was `Ready` with all extensions about 5 minutes after the sync.

The full procedure is in [Bare-metal Talos workers](../domains/hosts/bare-metal-talos.md).
