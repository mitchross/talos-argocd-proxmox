# ASUS NUC 13 Pro — November 11, 2026

This page records a new mini PC, an ASUS NUC 13 Pro Kit. It is **not in the cluster yet**. On
November 11, `omnictl get machines` listed only the 8 existing machines. Nothing here describes a
running node. It is a dated snapshot.

The plan is a bare-metal Talos worker named `asus-nuc13`. It has one NVMe drive, so it is
**compute-only**, with no Longhorn data disk, like `hp-elite-gen12`.

## Next steps

1. In the BIOS (F2), turn Secure Boot off and network boot on. F10 opens the one-time boot menu.
2. Boot it from the network. [booter](https://github.com/mitchross/talos-argocd-proxmox/blob/main/omni/pi-services/booter/README.md)
   serves Talos, and the machine appears in **Omni → Machines** in maintenance mode.
3. Collect the UUID and the disk serial with `omnictl get machinestatus <uuid> -o yaml`.
4. Open a template PR that adds a `Workers` block for `asus-nuc13`. Copy `hp-elite-gen13-workers`
   (`intel-ucode`, `i915`, `iscsi-tools`, `nfs-utils`, `nfsrahead`, `util-linux-tools`, watchdog,
   kubelet reserved, class labels) **without** the Longhorn disk patches.
5. After it joins, update this page, the [bare-metal table](../domains/hosts/bare-metal-talos.md),
   the [disk map](../domains/storage/disk-map.md) and the
   [topology](../domains/networking/topology.md), and change "joining" to a measured status.

The full procedure is in [Bare-metal Talos workers](../domains/hosts/bare-metal-talos.md).
